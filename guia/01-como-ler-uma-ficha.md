# Como ler uma ficha

Cada dia da série é um **pacote de produção**, não um card de estilo.

| Campo | O que é | Idioma |
|---|---|---|
| `day` / `variant` | Número do desafio (`75a` = dia 75, variante a) | — |
| `source_review` | `empty` · `discovered_needs_original_review` · `reviewed` · `inaccessible` · `superseded` | — |
| `style.name` | Nome que o autor deu | original |
| `style.prompt_published` | Bloco entre parênteses, se ele publicou | original, citado |
| `logline` | A frase da história | original, citado |
| `tools` | Só o que o post nomeia | — |
| `inspiration` | Quote, epopeia, handle | com URL |
| `thread` | herói, pranchas, prompt, quote | embed + link |
| `curator` | Nota nossa, se houver | PT-BR, rotulada |

`copy_policy` é sempre `link_only`.

Não misturar interpretação do curador com fala do autor. Se o fio não foi aberto, não completar de memória.
