# Ética, licenças, privacidade

| Item | Política |
|---|---|
| Vídeo / prancha | Não hospedar. Embed do X ou link. |
| Prompt / logline / bloco de estilo | Citação curta + URL do post. Sem reliceenciar. |
| Identidade do autor | Não imitar voz, persona ou “arquivo oficial”. |
| Ferramentas citadas | Nomear; não endossar. |
| Status `reviewed` | Só depois de abrir o fio original. |
| Busca automatizada | É descoberta, não verificação. |
| Takedown | Issue neste repo ou contato via GitHub `fulviofb`. |

O MIT deste repositório não cobre a obra da série. Ver `/NOTICE.md`.
